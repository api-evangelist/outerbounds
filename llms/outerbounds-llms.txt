# Outerbounds

> Outerbounds is a fully managed platform for building and deploying production-grade AI, ML, and data systems, built on the open-source Metaflow framework (originally developed at Netflix). It brings data, models, and agents together with software discipline — scalable, cost-efficient compute integrated with your existing cloud and data platforms, GPU access and autoscaling, and enterprise controls (SOC 2, HIPAA). Outerbounds is joining Anaconda. The developer surface is the Metaflow Python SDK and the outerbounds configuration CLI, not a public REST API.

## Products
- [Outerbounds platform](https://outerbounds.com): Fully managed Metaflow — cloud workstations, autoscaling compute, GPU access, deployments, governance.
- [Metaflow](https://metaflow.org): Open-source, human-centric framework for building and managing ML/AI systems.
